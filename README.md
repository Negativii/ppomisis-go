# ППОО МИСИС — лендинг для NFC-метки

Одна страница с приветствием и двумя кнопками: открыть мини-приложение
профсоюза обучающихся НИТУ МИСИС во **ВКонтакте** или в **Telegram**.
На NFC-метку помещается одна ссылка — она ведёт сюда.

**Ссылка:** https://negativii.github.io/ppomisis-go/

- ВКонтакте: https://vk.com/app54501350
- Telegram: https://t.me/ppoo_misis_bot

Страница — обычный `index.html` без сборки, публикуется через GitHub Pages
из ветки `main`.
